# guci / Porvia 骨瓷出口工作台

面向骨瓷出口的本地工作台，涵盖询盘提取、商品资料、印花和包装审核、英文 PDF 提案及版本管理。

## 本地运行

需要 Node.js 24 或更高版本。

```sh
npm ci
npm run dev
```

打开 [本机工作台](http://127.0.0.1:4186)。默认数据目录为 `.porvia/`，也可通过 `PORVIA_DATA_DIR` 使用独立目录。通过 `PORT` 可调整本机端口。

## 体验项目

1. 从「项目列表」打开「柠檬蓝花」示例，或新建空白项目。
2. 粘贴客户询盘或上传 TXT、MD、DOCX 或含文字的 PDF，核对自动提取的用途、数量、印花与包装要求。
3. 从「商品资料库」选入商品，或上传自己的主图。调整印花，并审核场景图和包装候选。
4. 在「提案与版本」查看选稿、保存和下载英文 PDF，并对照不同版本。

演示使用模拟询盘以及自制杯碟、印花和包装示意图。实际业务可上传自己的商品和设计素材。

## 可选模型

在「模型设置」中保存阿里百炼 API Key，可启用场景图和包装图对比。默认生成模型为 `qwen-image-2.1-turbo`。每次提交前，工作台展示发送给百炼的参考图和生成要求。
